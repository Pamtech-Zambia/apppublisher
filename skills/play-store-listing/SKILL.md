# Play Store Listing

## Required evidence
Understand what the app actually does before writing marketing copy. Prefer source/README/screens/user-provided feature list over assumptions.

## Baseline constraints
- title <= 30 characters
- short description <= 80
- full description <= 4000
Re-verify live policy before final submission.

## Writing rules
Use clear user benefits and real features. Avoid keyword stuffing, repeated terms, ranking/award/price claims, misleading affiliations, excessive emoji/special characters, and unsupported superlatives. Do not repeat the short description verbatim at the start of the full description.

## Localization
Translate meaning and product terminology naturally. Validate each locale independently. Screenshot text must be localized separately if text appears in screenshots.

## Workflow
Draft -> validate lengths -> metadata-risk scan -> compare claims against app evidence -> user review -> owner-mode update only with explicit confirmation.
